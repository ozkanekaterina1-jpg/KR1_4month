# Контрольная работа — TODO App

## Описание

Перед вами заготовка приложения списка задач (Todo App), написанного на **React + Vite**.
Вёрстка и компоненты уже реализованы. Ваша задача — реализовать всю логику приложения.

---

## Запуск проекта

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

---

## Задание

Откройте файл `src/App.jsx`. Внутри вы найдёте четыре функции, помеченные комментарием `TODO`. Необходимо реализовать каждую из них.

---

### 1. `handleAdd` — добавление задачи

При нажатии на кнопку «+»:

- Если `inputValue` пустая строка (или состоит только из пробелов) — ничего не делать.
- Создать новый объект задачи с полями `id`, `text` и `completed: false`.
- Добавить задачу в конец массива `todos`.
- Очистить поле ввода (установить `inputValue` в пустую строку).

> Подсказка: для генерации уникального `id` можно использовать `Date.now()`.

---

### 2. `handleToggle` — переключение статуса задачи

При нажатии на круглую кнопку рядом с задачей:

- Найти задачу в массиве по переданному `id`.
- Инвертировать её поле `completed` (`true` → `false`, `false` → `true`).
- Обновить массив `todos`.

---

### 3. `handleDelete` — удаление задачи

При нажатии на кнопку «✕» (появляется при наведении на задачу):

- Удалить задачу с переданным `id` из массива `todos`.

---

### 4. `handleClearCompleted` — очистка выполненных задач

При нажатии на кнопку «Очистить выполненные»:

- Удалить из массива `todos` все задачи, у которых `completed === true`.

---

### 5. `filteredTodos` — фильтрация задач

Переменная `filteredTodos` сейчас возвращает все задачи без фильтрации.  
Необходимо реализовать логику в зависимости от значения `filter`:

| Значение `filter` | Что показывать                        |
| ----------------- | ------------------------------------- |
| `'all'`           | Все задачи                            |
| `'active'`        | Только задачи с `completed === false` |
| `'completed'`     | Только задачи с `completed === true`  |

---

### 6. (Бонус) Обработка нажатия Enter

Доработайте компонент `src/components/TodoInput.jsx`:

- При нажатии клавиши **Enter** в поле ввода вызывать `onAdd`.

## Структура проекта

```
src/
├── components/
│   ├── Header.jsx         # Заголовок приложения
│   ├── TodoInput.jsx      # Поле ввода новой задачи
│   ├── TodoItem.jsx       # Одна задача в списке
│   ├── TodoList.jsx       # Список задач
│   ├── TodoFilter.jsx     # Кнопки фильтрации (Все / Активные / Выполненные)
│   └── TodoFooter.jsx     # Счётчик задач и кнопка очистки
└── App.jsx                # Главный компонент — здесь вся логика
```
